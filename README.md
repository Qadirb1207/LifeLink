# 🩸 Blood Management System

## About the Project
The Blood Management System is a Java-based group project developed for our Software Engineering course. It helps manage blood donors, blood groups, blood availability, and blood requests.

## Technologies Used
- Java
- Java Swing
- Data Structures
- IntelliJ IDEA

## Features
- Add and manage donor records.
- Search donors by blood group.
- Manage blood inventory.
- Record blood requests.
